# jitz.app

The website for Jitz, a training log for jiu-jitsu. Served by GitHub Pages at https://jitz.app.

- `/` home page
- `/privacy/` privacy policy
- `/support/` support and FAQ

Plain static HTML and CSS with no build step and no third-party requests. Fonts (Inter, Montserrat) are self-hosted under `assets/fonts` under the SIL Open Font License.
